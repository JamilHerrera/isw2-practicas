## 🧪 Correr los tests localmente

Requiere Node.js 20 o superior. No hay dependencias que instalar.

```bash
npm test
```

Corre las suites de las prácticas 4 y 5 y termina con código de salida distinto
de cero si alguna falla, que es exactamente lo que evalúa el pipeline.
